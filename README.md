# FCAI-CU (نسخة بدون سيرفر ولا تسجيل دخول)

موقع ثابت على GitHub Pages. المواد في `content.json` والملفات المرفوعة في `files/`.

## إضافة مواد (على جهازك)
1. نزّل Node.js من nodejs.org (مرة واحدة).
2. دبل كليك على `start-admin.bat` وهيفتح http://localhost:3000/admin
3. اعمل مجلدات (First year > 1 Semester > Week 1 > Lecture...) وضيف ملفات جواها.
   اضغط مطولاً على أي عنصر واسحبه لمجلد تاني أو لترتيب مختلف.
4. اقفل النافذة السودا.

## النشر
بعد أي تعديل ارفع `content.json` وفولدر `files/` على GitHub (GitHub Desktop: Commit ثم Push).
GitHub Pages بيحدّث الموقع بعد دقيقة.
